# Distribution status

This fork does not maintain a separate SourceForge project and does not upload images to the upstream project's SourceForge page.

For temporary testing, build workflows may attach an ISO and checksums as a GitHub Actions artifact with seven-day retention. An Actions artifact is not permanent release hosting. No long-term ISO distribution host has been selected, and the workflows do not create public GitHub Releases.

Use only an official Windows ISO that you are licensed to use. Signed Microsoft download URLs expire and must not be committed to the repository or included in public issues.

For build instructions, profile limitations, and the validation checklist, see [README.md](README.md).
