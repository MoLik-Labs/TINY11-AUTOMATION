About Flow Lab.

An experiment in a calmer desktop experience.

IMPORTANT

A visual prototype, not an operating system.

Independent and not affiliated with FlowOS. This browser preview cannot install or run Windows, Linux, Android, macOS or iOS applications.

Real application support requires separate runtimes, compatible hardware and attention to licensing. No universal compatibility is promised.

See FLOW.md in the project repository for further details.
